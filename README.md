**Smaran** (स्मरण) — *Sanskrit for Remembrance, Recollection, Deep Memory.*

## 🔥 Features That Hit Different

<br/>

### `📄` **Smart Notes-to-Summary Engine**
> *400 pages → 1 page. Exam relevance: 100%.*

Your notes are a jungle. Smaran is the machete.

Feed it your lectures, textbooks, test papers — anything. It reads everything, understands the syllabus, detects the patterns, and outputs a **clean, one-page masterpiece** built for the exam you're actually sitting.

Not a generic summary. A *targeted* summary. Big difference.

```
INPUT  →  400pg notes + PYQ analysis
OUTPUT →  1 crisp page of exactly-what-will-be-asked
TIME   →  Under 60 seconds
```

---

<br/>

### `🎧` **Instant Notes-to-Podcast Conversion**
> *Learn while the world moves. Your ears never waste time.*

Because your eyes can't always be on a screen.

Smaran transforms your summaries into **auto-generated audio podcasts** — voiced, paced, and structured like revision sessions, not robot recitations.

Listen while:
- 🚶 Walking to the exam hall
- 🚌 Sitting on the bus
- 🛌 Lying in bed at midnight
- 🍳 Making breakfast at 7 AM

**The exam prep that follows you everywhere.**

---

<br/>

### `📚` **PYQ Intelligence Engine**
> *Stop studying everything. Start studying what matters.*

This is the secret weapon.

Smaran doesn't just summarize — it **thinks like an examiner**. By analyzing Previous Year Questions across years and subjects, it detects:

| Signal | What Smaran Finds |
|--------|-------------------|
| 🔁 Repeat topics | Questions asked 3+ times in 5 years |
| 📈 Rising trends | Topics gaining frequency year over year |
| 💡 Golden topics | High-value, frequently-missed areas |
| ⚠️ Danger zones | Topics you've avoided that always appear |

**The result:** You spend 80% of your time on the 20% that actually fills your marksheet.

---

<br/>

### `🧠` **Adaptive Exam Preparation**
> *It knows your syllabus. It knows your gaps. It knows what to push.*

Smaran isn't a static tool. It **learns your patterns**.

- Weak in Organic Chemistry? It front-loads it.
- Strong in History? It fast-tracks your revision there.
- Exam in 48 hours? It switches to *crisis mode* — maximum impact, minimum time.

Adaptive. Personal. Ruthlessly efficient.

---

<br/>

### `🗂` **Unified Revision System**
> *Every format you need. Auto-generated. All in one place.*

From one upload, Smaran generates your **complete revision arsenal:**

```
Your Notes
    │
    ├── 📄 One-Page Summary        (the big picture, fast)
    │
    ├── 🃏 Quick Revision Cards    (concept by concept)
    │
    ├── 🗺️  Mind Maps & Flow Diagrams (visual memory anchors)
    │
    └── 🎧 Audio Podcast           (ears-only revision mode)
```

No more cobbling together 5 different apps.
**One upload. Full arsenal.**

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/your-username/smaran.git

# Navigate into it
cd smaran

# Install dependencies
npm install

# Set your environment variables
cp .env.example .env.local
# Add your API keys to .env.local

# Fire it up
npm run dev
```

Visit `http://localhost:3000` and upload your first set of notes.

*Your first one-page summary will be ready in under 60 seconds.*
